# 盲盒抽奖系统 v3.0

## 版本信息
- **版本**: v3.0
- **日期**: 2026-06-12
- **更新内容**: 修复时间设置、优化倒计时显示、完善错误提示

## 功能模块

### 1. 首页倒计时
- 支持4种状态显示：无限制/未开始/进行中/已结束
- 默认显示 `--`，不强制覆盖云端配置
- 后台静默同步云端数据

### 2. 员工身份验证
- 白名单机制控制参与资格
- 手机号格式验证（支持所有号段）
- 友好的错误提示："抱歉，您暂无抽奖资格"

### 3. 管理员后台
- 密码验证保护
- 时间设置使用 datetime-local（日期时间合并）
- 格式提示：`(格式: 2026-06-15 09:00)`

### 4. 白名单管理
- 支持添加/删除/清空
- 开关控制启用状态
- Excel/CSV 导入导出

### 5. 抽奖流程
- 10种奖品随机抽取
- 概率可配置
- 中奖记录保存和展示

### 6. 云端同步
- localStorage 本地持久化
- Cloudflare Worker 云端备份
- 数据不丢失

## 部署方式

### 前端（GitHub Pages）
1. 将 `index.html` 上传到 GitHub 仓库
2. 开启 GitHub Pages 功能
3. 访问 `https://你的用户名.github.io/仓库名/`

### 后端（Cloudflare Worker）
1. 登录 Cloudflare Dashboard
2. 创建新的 Worker
3. 将 `worker-pure.js` 代码粘贴进去
4. 部署并获取 Worker URL
5. 修改前端代码中的 `API_BASE` 为你的 Worker URL
