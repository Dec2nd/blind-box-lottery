## 版本历史

### v6.0 (2026-07-27) 🌟 重大更新
- 🔒 **后端白名单校验**：不在白名单的员工无法提交抽奖记录，彻底杜绝幽灵记录
- ⏰ **后端时间校验**：不在时间范围内无法提交，即使前端被绕过也无法非法参与
- 🌍 **UTC 时间戳存储**：修复时区差异导致的时间校验错误（如北京时间 10:00 被误判为不在范围内）
- ⚡ **动画并行提交**：网络请求在动画期间并行发起，动画结束即时显示奖品，消除 1-2 秒卡顿

### v5.0 (2026-07-21)
- 🔐 **云端单一权威防重**：抽奖资格校验仅以 Cloudflare D1 records 表为准，彻底解决换浏览器/清缓存即可重复参与的问题
- 📋 **白名单双字段匹配**：手机号 + 姓名必须同时与白名单一致才能参与，防止盗用手机号
- 🚫 **断网严格模式**：云端不可达时直接拒绝参与，不再降级到本地 localStorage
- 🧹 **新一轮活动一键重置**：后台「一键清空开奖记录」按钮增强（二次确认 + 错误提示 + 状态显示）
- 💬 **精准错误提示**：区分「不在白名单」「姓名不一致」「云端不可用」等不同场景

### v4.0 (2026-07-05)
- 🔧 **修复 Excel 导入失败**：解决 `XLSX is not defined` 报错
- 🛡️ **多 CDN 降级机制**：4 个 CDN 源自动切换（jsdelivr → unpkg → cdnjs → bootcdn）
- ⏳ **加载状态检测**：库未加载时给出友好提示，而非直接报错
- 📊 **导入健壮性增强**：
  - 支持更多列名识别（员工姓名、手机号、联系电话等）
  - 自动处理 Excel 手机号带小数点的问题
  - 统计无效数据条数并提示
  - 空工作表检测、文件读取失败处理
- 📤 **导出功能同步增强**：导出 Excel 同样增加库加载检测

### v3.0 (2026-06-12)
- 修复时间设置、优化倒计时显示、完善错误提示

## 功能模块

### 1. 首页倒计时
- 支持 4 种状态显示：无限制 / 未开始 / 进行中 / 已结束
- 默认显示 `--`，不强制覆盖云端配置
- 后台静默同步云端数据

### 2. 员工身份验证 🔐（v5.0 重构）
- **白名单双字段匹配**：手机号 + 姓名同时一致才能通过
- **云端单一权威**：参与记录仅以 Cloudflare D1 records 表为准
- **断网严格模式**：云端不可达时拒绝参与，避免绕过
- 精准错误提示：「不在本期白名单」「姓名与白名单不一致」「云端服务不可用」

### 3. 管理员后台
- 密码验证保护
- 时间设置使用 datetime-local（日期时间合并）
- 格式提示：`(格式: 2026-06-15 09:00)`

### 4. 白名单管理
- 支持添加 / 删除 / 清空
- 开关控制启用状态
- Excel / CSV 导入导出（v4.0 增强版）
  - 多 CDN 自动降级，确保 Excel 解析库可用
  - 智能识别列名：姓名 / 名字 / 员工姓名、手机 / 电话 / 手机号 / 联系电话
  - 自动处理 Excel 数字格式的手机号
  - 导入结果统计：新增人数、重复跳过、无效数据

### 5. 抽奖流程
- 10 种奖品随机抽取
- 概率可配置
- 中奖记录保存和展示
- 动画期间并行提交网络请求，结束即时显示结果（v6.0 优化）

### 6. 新一轮活动重置 🆕
- 后台「一键清空开奖记录（重新开始）」
- 二次确认防误操作
- 清空后所有白名单成员可重新参与
- 不影响白名单、时间、概率等其他设置

### 7. 云端同步
- localStorage 本地持久化
- Cloudflare Worker 云端备份
- 数据不丢失

## 部署方式

### 前端（GitHub Pages）
1. 将 `index.html` 上传到 GitHub 仓库
2. 开启 GitHub Pages 功能
3. 访问 `https://你的用户名.github.io/仓库名/`

### 后端（Cloudflare Worker）
1. 登录 Cloudflare Dashboard
2. 创建新的 Worker
3. 将 `worker-pure.js` 代码粘贴进去
4. 部署并获取 Worker URL
5. 修改前端代码中的 `API_BASE` 为你的 Worker URL

## 从 v5.0 升级到 v6.0

**需要替换 `index.html` 和 `worker-pure.js`**（两个文件都有改动）。

升级后变化：
- ✅ 不在白名单的员工无论如何都无法产生记录（后端双重校验）
- ✅ 不在时间范围内无法参与（后端校验，不受时区影响）
- ✅ 北京时间设置 10:00-17:00 后，10:00 准时可参与，不再被误判
- ✅ 开盒动画结束立即显示奖品，无卡顿等待

## 技术栈
- 前端：纯 HTML + CSS + JavaScript（无框架依赖）
- 后端：Cloudflare Worker（JavaScript）
- 数据存储：localStorage + Cloudflare D1
- Excel 解析：SheetJS (xlsx)，多 CDN 自动降级
